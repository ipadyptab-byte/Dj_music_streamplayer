# How to run this Music Player locally

1. **Install Python**: Make sure you have Python 3.8+ installed on your machine.
2. **Install Dependencies**: Open your terminal and run:
   ```bash
   pip install flask yt-dlp
   ```
3. **Copy Files**: Download or copy `main.py` and the `static/` folder (including `index.html`) to a directory on your computer.
4. **Run the Server**: In your terminal, navigate to that directory and run:
   ```bash
   python main.py
   ```
5. **Open in Browser**: Visit `http://127.0.0.1:5000` in your web browser.

Note: Ensure you have a stable internet connection for YouTube search and playback to work.
