🗄️ Database Connection & Persistent Storage

Connect an external PostgreSQL / Supabase / Neon / Cloud SQL database. When connected, all uploaded advertisement tracks, prayer tracks, schedules, and settings are stored permanently in the database and will never disappear even when cloud containers restart or next day.
Example (Supabase): postgresql://postgres:MyPass@db.xyz.supabase.co:5432/postgres
Example (Neon): postgresql://neondb_owner:pass@ep-cool.us-east-2.aws.neon.tech/neondb?sslmode=require
Browser Audio Vault: Full audio files for advertisements and prayers are also stored directly in this browser's local vault (IndexedDB). If the cloud container restarts overnight, the player automatically restores and plays tracks from your browser vault without any interruption!

You can also use Direct Public Audio URLs (hosted on Amazon S3, Supabase Storage, Google Drive, Archive.org, or any web server). Direct URLs are permanent and will never be lost regardless of server state.
Local Filesystem Paths: You can specify exact file or directory paths on your PC or server (e.g. C:\Music\Prayer.mp3, D:\DeviJewellers\Ads, or /var/audio/prayer.wav). The player reads and streams them directly with zero loss.

💻 Install DJ StreamPlayer on Windows

1
In Google Chrome, Microsoft Edge, or Brave, look at the right side of the address bar at the top.
2
Click the App Install icon (computer monitor / ⊕ symbol) or click the browser menu (⋮) → "Install DJ Music StreamPlayer" or "Apps → Install this site as an app".
3
Click Install. DJ StreamPlayer will be added to your Windows Start Menu, Taskbar, and Desktop with dedicated window controls.
